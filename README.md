# ACKER-RUN

Ein spielbarer erster Prototyp als statische Web-App.

## Lokal testen
Öffne `index.html` in einem aktuellen Browser.

## Auf GitHub Pages veröffentlichen
1. Erstelle auf GitHub ein neues Repository, z. B. `acker-run`.
2. Lade `index.html` in das Repository hoch.
3. Öffne **Settings → Pages**.
4. Wähle bei **Build and deployment** die Quelle **Deploy from a branch**.
5. Wähle `main` und `/ (root)`, dann **Save**.
6. Nach dem Veröffentlichen findest du dort deinen öffentlichen Spiele-Link.

## Was dieser Prototyp bereits kann
- Nickname auf dem Gerät speichern
- Spielfeld von oben mit Acker, Ziel-Bierkrug, Traktoren und Kühen
- Hoch-/Runter-Steuerung per Touch oder Tastatur
- Drei Leben, Kollisionen, steigende Schwierigkeit und bis zu 1.000 Krüge
- einfache synthetische Hintergrundmelodie zum Ein-/Ausschalten
- persönlicher Rekord lokal im Browser speichern

## Noch nicht online
Globale Bestenlisten, Gruppen, Einladungs-Codes und geräteübergreifende Spielerkonten benötigen einen Online-Dienst mit Datenbank und Sicherheitsregeln. Diese Funktionen sind bewusst noch nicht als echt dargestellt. Sie sind der nächste Entwicklungsschritt.
